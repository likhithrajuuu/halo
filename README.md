# Halo

A calm, precise focus timer for macOS, Windows and Linux.

[**Download**](https://github.com/likhithrajuuu/halo/releases/latest) · [Website](https://halo.likhithraju.tech)

- A focus timer with short and long breaks, and session dots that show your progress
- A live countdown in your menu bar, with a popover to pause or skip
- Tasks, so every session is logged against what you worked on
- Statistics by day, week and month, with streaks and a daily goal
- A mini window that stays on top
- Free, with no account. Your data stays on your device.

## Install

**macOS (Homebrew)**

```sh
brew install --cask likhithrajuuu/tap/halo
```

**Direct downloads** are on the [Releases page](https://github.com/likhithrajuuu/halo/releases/latest):

| Platform | File |
|---|---|
| macOS 11+ (Apple silicon and Intel) | `Halo_<version>_universal.dmg` |
| Windows 10/11 (64-bit) | `Halo_<version>_x64-setup.exe` or `.msi` |
| Linux (64-bit) | `.AppImage`, `.deb` or `.rpm` |

### First launch

Halo is not yet signed with a paid developer certificate, so your system may ask you to confirm it once.

- **macOS:** if it says the app can't be opened, right-click Halo and choose Open, or go to System Settings, Privacy & Security, and click Open Anyway. Installing with Homebrew skips this.
- **Windows:** if SmartScreen appears, choose More info, then Run anyway.
